# Contributing

Welcome to GitMapsGame! This is a public educational prototype with fictional terrain and zero production integrations.

Good contributions include accessibility improvements, diagram corrections, additional synthetic failure scenarios, offline test coverage, and clearer explanations of independent release authorization.

Before contributing:
1. Open an Issue describing the crossing you want to improve.
2. State what files you expect to touch and what evidence will prove success.
3. Submit a focused PR with test output and screenshots when useful.
4. Keep all sample data entirely fictional.
5. Never submit credentials, private company code, client data, real deployment URLs or proprietary fixtures.

Maintainers review contributions; green CI does not imply automatic approval or any deployment authority. The sample workflow only runs tests.
